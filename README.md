# منيو مطعم عجيبة الرقمي | Ageba Restaurant Digital Menu

المنيو الرقمي الرسمي لمطعم **«عجيبة»** (البدرشين — شارع عباس عناني بجوار كازيون ماركت).

## 🌟 المميزات
- **هوية بصرية حقيقية:** ألوان مستوحاة مباشرة من لوجو المطعم والمنيو الورقي (فحمي داكن `#121214`، أحمر قرمزي `#C41E24`، أصفر الجبنة السايحة `#F5A623`).
- **Mobile-First Design:** تجربة سلسة تشبه التطبيقات الأصلية ومناسبة تماماً لزوار فيسبوك على الهواتف الذكية.
- **حركات وتفاعلات فيزيائية ناعمة:** مدعومة بـ `framer-motion` و `lucide-react`.
- **بحث لحظي ذكي (Smart Global Arabic Search):** تطبيع ذكي للحروف العربية (همزات، تاء مربوطة، ياء) والبحث في كافة الأقسام دفعة واحدة.
- **تخصيص كامل للأصناف:** دعم اختيار الأحجام (S / L للبيتزا) والإضافات (Addons للكريب والبيتزا).
- **سلة طلبات عائمة وفاتورة واتساب:** توليد فاتورة شراء منظمة وإرسالها مباشرة لرقم واتساب المطعم `01142400434`.

## 🛠️ التقنيات المستخدمة
- React 19
- Framer Motion
- Lucide React
- Tailwind CSS
- esbuild

## 🚀 التشغيل المحلي
```bash
# تثبيت الحزم
npm install

# بناء المشروع
npm run build

# تشغيل خادم محلي
python -m http.server 8000
```
افتح المتصفح على: `http://localhost:8000`
